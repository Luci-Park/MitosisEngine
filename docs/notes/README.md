# Notes

Research, benchmarks, API comparisons, spike write-ups, half-formed designs.
No review bar - write fast, write things you are not sure about. The alternative
is that the work lives in a browser tab and dies with it.

- One file per topic, `YYYY-MM-DD-short-title.md`, from [TEMPLATE.md](TEMPLATE.md).
- The date is the point: a note is a snapshot, not a maintained document. Nobody
  keeps it current.
- Say who wrote it and what state it is in - exploring, done, abandoned.
- Nothing here binds anyone. A note that becomes a rule turns into a
  [decision](../decisions/README.md); one that becomes a module turns into a
  [module document](../modules/README.md).

## Worth writing

- "I benchmarked A against B, here are the numbers and the caveats."
- "I tried this for two days and it does not work, here is why."
- "This is how another engine solves the problem we are about to hit."
- "Here is my half-designed plan, tear it apart."

The second is the most valuable and the least written. A recorded dead end saves
the next person the same two days.
