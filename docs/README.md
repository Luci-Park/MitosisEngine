| Writing | Goes in | Template |
|---|---|---|
| Reasoning behind a choice that constrains others | `decisions/` | [TEMPLATE](decisions/TEMPLATE.md) |

| Research, benchmarks, dead ends | `notes/` | [TEMPLATE](notes/TEMPLATE.md) |
| A rule everyone follows | `CONVENTIONS.md` | [CONVENTIONS.md](CONVENTIONS.md) |
| How to do a task | `EXTENDING.md` | [EXTENDING.md](EXTENDING.md) |
